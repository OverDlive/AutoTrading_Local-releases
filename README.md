# EUKK Trading — Desktop Releases

EUKK Trading Python 데스크톱 앱의 공개 배포 저장소입니다.

**[최신 버전 다운로드](https://github.com/OverDlive/AutoTrading_Local-releases/releases/latest)**

| 파일 | 운영체제 |
|---|---|
| `EUKK-Trading-X.Y.Z-windows-x64.zip` | Windows x64 |
| `EUKK-Trading-X.Y.Z-macos-arm64.tar.gz` | macOS Apple Silicon |
| `EUKK-Trading-X.Y.Z-macos-x64.tar.gz` | macOS Intel |
| 각 파일의 `.sha256` | 다운로드 무결성 확인 |

Windows에서는 압축을 전용 설치 폴더에 풀고 `EUKK Trading.exe`를 실행하세요.
macOS에서는 압축을 풀고 `EUKK Trading.app`을 Applications 폴더로 옮겨 실행하세요.
자동 업데이트를 사용하려면 앱 설치 폴더의 부모 디렉터리에 쓰기 권한이 있어야 합니다.

프로그램의 **환경 설정 → 업데이트**에서 새 버전을 확인하고 설치할 수 있습니다.
다운로드와 업데이트에 GitHub 로그인이나 접근 토큰은 필요하지 않습니다.

릴리스는 빌드·테스트를 통과한 배포 파일과 SHA-256 체크섬으로 구성됩니다.
소스 코드, git 이력, 개발 자료, 사용자 설정·계좌 정보는 이 저장소에 게시하지 않습니다.
GitHub가 제공하는 자동 생성 Source code archive에는 이 안내 문서만 들어 있습니다.

현재 배포 파일은 코드 서명·macOS 공증을 포함하지 않습니다.
